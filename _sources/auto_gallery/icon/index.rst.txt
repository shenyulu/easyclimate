ICON and Triangular Mesh Visualization
--------------------------------------

Examples for plotting ICON triangular meshes and ICON variables stored on
cell centers. The gallery covers mesh edges, native triangular cell fills,
cell-centered filled and line contours, and ICON wind-vector displays.
